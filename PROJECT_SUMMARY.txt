0. PROJECT OVERVIEW
================================================================================

TradeX is a browser-only paper trading platform. Users get a virtual $10,000
wallet on signup, trade 20 default US stocks (100 in data file) at live Finnhub
prices, compete on a leaderboard, and set price alerts with optional email.
Admins manage traders, fund requests, and audit logs via Supabase RPCs.

Architecture:

  Browser (React SPA)
    ├── Supabase Auth + Postgres (RLS) — users, wallets, trades, watchlist, alerts
    ├── Finnhub REST — quotes, news (queued + cache)
    ├── Finnhub WebSocket — Dashboard, Portfolio, Watchlist (throttled UI)
    ├── Finnhub CDN + TradingView SVG — stock logos (fallback chain)
    ├── TradingView CDN — charts, tape, widgets
    └── Supabase Edge Function — send-price-alert (Resend email)

Documentation:
  README.md                      — Quick start, deploy
  supabase/SUPABASE_SETUP.md     — Supabase setup (SQL, Auth, emails, alerts §11)
  PROJECT_SUMMARY.txt            — This file (includes production checklist §8)

DSA module (academic):
  src/lib/dsa.js — PortfolioMap (HashMap), TransactionStack (Stack),
                   binarySearch, sortByField

7. P&L & METRICS
================================================================================

  Unrealized P&L = holdings market value − cost basis
  Realized P&L   = sum(sell proceeds − cost) on SELL rows
  Total return % = account value vs wallets.total_deposited
  Admin Top Traders ranked by realized P&L (net_flow), not wallet balance
